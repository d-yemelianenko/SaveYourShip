# SaveYourShip Game (Unity)

Projekt powstał w ramach zespołowej pracy semestralnej na studiach informatycznych.Projekt stworzony w Unity. Gra oparta na mechanicę eksploracji, interakcji z przedmiotami oraz systemem ekwipunku. 

## 👥 Zespół

Projekt tworzony w zespole 3-osobowym. Praca semestralna była prowadzona zgodnie z metodyką SCRUM.


## 🎮 Moje zadania w projekcie

- Pełnienie roli **Scrum Mastera** (2 sprinty): prowadzenie Daily, organizacja zadań w Kanban
- **Menu główne i menu pauzy** – projektowanie i implementacja
- **Obsługa dźwięków** w menu i interfejsie
- **Pasek szybkiego wyboru** – logika i UI
- **Ekwipunek gracza** – przeciąganie przedmiotów, zmiana aktywnego narzędzia
- Obliczanie **pasków chłodu i głodu** postaci

## 🛠️ Technologie

- Unity
- C#
- System zarządzania zadaniami: Kanban, tablice fizyczne i cyfrowe
- Organizacja pracy: Scrum
  
## 📁 Zawartość repozytorium

- Kod gry w C#
- Sceny Unity
- Dokumentacja użytkownika
